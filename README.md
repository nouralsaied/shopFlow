# ShopFlow

ShopFlow هو نموذج واجهة متجر إلكتروني مبني باستخدام HTML وCSS وJavaScript، مع تصميم متجاوب ودعم الوضعين الفاتح والداكن. تُحمّل بيانات المنتجات من [DummyJSON](https://dummyjson.com/).

## الميزات

- استعراض المنتجات والتفاصيل والمنتجات المميزة.
- البحث والتصفية حسب الفئة والسعر والتقييم، مع خيارات لترتيب النتائج.
- تقسيم المنتجات إلى صفحات؛ تعرض كل صفحة 24 منتجًا.
- إضافة المنتجات إلى المفضلة أو سلة التسوق.
- تعديل كميات السلة وحساب الشحن والإجمالي.
- مسار إتمام طلب متعدد الخطوات، مع حفظ الطلبات محليًا.
- حفظ السلة والمفضلة والطلبات وتفضيل المظهر في `localStorage`.
- تصميم متجاوب مع الشاشات المختلفة.

## التشغيل

لا يحتاج المشروع إلى تثبيت حزم أو خطوات بناء. شغّل خادم ملفات محليًا من مجلد المشروع، لأن الصفحات تستخدم وحدات JavaScript:

```bash
python -m http.server 8000
```

ثم افتح <http://localhost:8000> في المتصفح. يمكن أيضًا تشغيل المشروع باستخدام إضافة مثل Live Server في Visual Studio Code.

يتطلب تحميل المنتجات اتصالًا بالإنترنت للوصول إلى DummyJSON.

## الصفحات

| الملف                       | المحتوى                                 |
| --------------------------- | ---------------------------------------  | 
| `index.html`                | الصفحة الرئيسية والمنتجات المميزة     |
| `products.html`             | قائمة المنتجات والبحث والتصفية والترقيم|
| `product.html`              | تفاصيل منتج محدد                        |
| `cart.html`                 | سلة التسوق                              |
| `checkout.html`             | إتمام الطلب وعرض الطلبات المحفوظة      |
| `products.html?favorites=1` | المنتجات المفضلة                        |

## ملاحظات

- بيانات المنتجات تأتي من DummyJSON، بينما تُحفظ بيانات السلة والمفضلة والطلبات في متصفح المستخدم باستخدام `localStorage`.
- الدفع في صفحة إتمام الطلب تجريبي فقط؛ لا تُدخل بيانات بطاقة حقيقية. لا تتم معالجة مدفوعات فعلية.
